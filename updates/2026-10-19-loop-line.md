## What changed

`bash scripts/prune-counter.sh --prune` prints one more line, `Loop: N escapes and M rule tags dated in
this window of K features`: the `Escaped` retro lines (bugs found after QA passed) and the `(from …)`
rule tags dated inside the window. The prune proposal's **Trend** line now quotes it.

## Why

The prune already writes its own report without the owner (the proposal is written when it is due), and
a retro only adds a rule from a miss. What was missing is a number per project that shows whether the
loop does anything: how many bugs escaped and how many rules were added in the same window.

## How to apply

Merge the `escaped` count and the `Loop:` print in `scripts/prune-counter.sh`, and the one-sentence
change to the **Trend** line in `harness/templates/prune.md`.
