New optional `autonomous` module, rules and templates first: an unattended run from a product brief to the first version on its own branch (`auto/v1` by default). An Opus director writes the product, tech, design and finance docs and the feature order, the owner approves them once, and each feature then runs through the normal harness in a fresh session. The Technical Lead approves its own plans under the module's run rules, writes owner-only items to the version checklist's § Needs you, and ends each feature with a short card for the features after it. A run stops only when a feature runs out of tries or the run budget is spent. The module adds `harness/templates/auto/`, an `auto:` config block (off), and one line in `harness/TECHNICAL_LEAD.md` and each plan template's § Approval, all marked so that installs without the module are unchanged. `/morph-module` and `/morph-doctor` know it. The driver script and the `/morph-auto` skill follow in a later release.
