**`/morph-share` evidence names.** Step 7 of `/morph-share` now asks whether the evidence summary goes out under the project's name or anonymously before it creates any branch or file, and names the branch, file and pull request from that answer. An anonymous share gets a neutral random slug (`showcase/anon-4f2k`), never a descriptive alias, and the PR text must not say what the project is. It also stops if `scripts/evidence.sh` reports unreadable entries instead of forcing past it.
 The PR template has a line for evidence summaries (generated by, named or anonymous) and its checklist separates them from lessons.
