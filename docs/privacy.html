Privacy

Last updated 2026-10-19

Morphness is an open-source plugin for Claude Code, made by Antarsoft. It has no servers, no accounts and no analytics. This page covers the plugin and this website.

The plugin

  • Nothing is collected. The plugin's skills run inside your own Claude Code session and work only on files in your repository.
  • What it writes. /morph-init asks for the project owner's name and GitHub handle and saves them in harness.config.yml in your repository, so the harness knows who approves plans. They stay in your repository and are never sent to Morphness or Antarsoft.
  • Update checks. /morph-update, /morph-doctor and the prune's upstream check read release notes and template text from github.com/antarsoft/morphness with plain read-only requests. They execute nothing, send nothing about your project and need no account; GitHub's privacy statement applies to those requests. When GitHub can't be reached, or with updates.source: local in harness.config.yml, they fall back to a local copy.
  • Sharing is opt-in. /morph-share drafts anonymised lessons for the public Morphness catalog. Nothing is sent unless you approve it. You then open a pull request on GitHub with your own account, and GitHub's privacy statement applies to it.
  • Claude. Like any Claude Code plugin, the skills run through Claude. Anthropic's privacy policy covers what Claude Code sends to Anthropic.

This website

  • The site is hosted on GitHub Pages. GitHub may log visitor IP addresses for security, as described in GitHub's privacy statement.
  • The page sets no cookies and runs no analytics or tracking scripts.
  • Your browser fetches the public star count from the GitHub API (api.github.com) to show it on the page.

Contact
