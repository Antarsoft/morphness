An agent harness that morphs into your project's own

Morphness is an open-source, multi-agent harness for Claude Code. A Technical Lead plans, Full-stack builds, QA verifies, and a retro and prune loop turns what goes wrong into rules that fit your project.

Your agent rules need a delete button

If you've been writing CLAUDE.md rules, subagents and checklists by hand, you know they only grow. Morphness is that work packaged, with a loop that keeps it short and true.

Plan first, then build

The Technical Lead writes a plan with testable acceptance criteria and waits for your approval before any code is written.

QA is never skipped

A separate QA agent runs your checks and records evidence for every criterion, so "done" means verified, not claimed.

Learns from its mistakes

After every feature, a short retro turns what went wrong into rules. Every ten features, a prune questions the rules that never fired.

Works on any codebase

New or existing repos, any language or framework. It keeps your CLAUDE.md, shows a diff for settings and lands everything on a branch.

Safe by default

Secrets and pushes to protected branches are denied from the first install. Agents never write to a shared remote environment.

Yours to configure

Branches, checks, modules, risk areas, models and effort live in one harness.config.yml. Every rule is a Markdown file you own.

A small team of agents, with a process

You talk to the Technical Lead in the main chat. It delegates the work and never writes code itself.

Technical Lead

Plans each feature, gets your approval, delegates and keeps the rules current.

Default: opus, high effort

Full-stack

Builds the approved plan and its tests.

Default: opus, high effort

QA

Runs the checks and validates every acceptance criterion.

Default: sonnet, high effort

Legal writer

Writes wording that makes a legal promise, when a feature needs it.

Default: fable or opus, high effort

Install

The setup scans your repo, then asks a short series of questions, each with a suggested answer. It suggests skills, connectors and lessons that fit your stack, and installs only the ones you accept.

Ask your agent

In any Claude Code session inside your repo:

Install Morphness from https://github.com/antarsoft/morphness in this repo. Follow its INSTALL.md.

Or as a plugin

Add the marketplace, install, then run the setup:

/plugin marketplace add antarsoft/morphness
/plugin install morphness@morphness
/morph-init

Your first feature

  1. Ask the Technical Lead: plan <feature>.
  2. Read the plan and its acceptance criteria, then approve it.
  3. Full-stack builds it, then QA checks every criterion.
  4. You get a steps file (anything only you can do) and a short retro.

From the community, for the community.

Rules that prove themselves can help the next team

When a prune shows a rule caught a real problem, /morph-share drafts a PR to the shared catalog. /morph-doctor offers new lessons that match your stack.
