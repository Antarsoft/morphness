# Evidence summaries

How the harness worked in real projects, as counts and rates generated by `scripts/evidence.sh` and
shared with `/morph-share` only on the owner's yes ([CONTRIBUTING.md](../CONTRIBUTING.md) § Showcase).
One file per project (or per alias when the owner wants it anonymous). Each keeps the script's
"Read with care" list: the figures are agent-recorded, escapes are under-counted, and there is no
control run, so they show what the process produced, not what it saved.
